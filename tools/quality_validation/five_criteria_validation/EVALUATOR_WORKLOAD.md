# Estimated evaluator workload — Five Classical criteria

Finite study. Three independent raters + facilitator.

---

## Per rater

| Activity | Images | Est. time / image | Subtotal |
|----------|-------:|------------------:|---------:|
| Rubric + instructions reading | — | — | 30–45 min |
| Group calibration walkthrough | 10–12 | ~3–4 min (discussion) | 40–50 min |
| Independent calibration practice | 6 | 4–6 min | 25–40 min |
| Validation wave | **40** | **4–6 min** | **2.7–4.0 h** |
| Breaks / admin | — | — | 20–30 min |
| **Total per rater** | | | **≈ 4.5–6.5 hours** |

Five criteria per image (vs two in Noise/Ringing) drives the higher per-image time. Prefer `eval_web` to reduce CSV friction.

---

## Facilitator

| Activity | Estimate |
|----------|----------|
| Collection + licensing + strata (after approval) | 6–12 h |
| Pack blinding + checklist | 1–2 h |
| Calibration analysis + remediation | 1–2 h |
| IRR + consensus after lock | 1–2 h |
| Frozen machine compare + decision report | 2–4 h |
| **Facilitator total** | **≈ 11–22 h** |

---

## Scheduling suggestion

1. Day 1: rubric + group calibration + independent practice.  
2. Day 2–3: validation wave in two sittings (~20 images each) to limit fatigue.  
3. Day 4+: facilitator lock → IRR → (if pass) machine compare.

Do not ask raters to rate Noise/Ringing in the same sitting for this pack.
